# OCR Translation App

A powerful Next.js application that extracts text from images, videos, and documents with translation capabilities supporting multiple languages including Urdu and English.

## Features

- **Multi-format Support**: Upload images, videos, and documents (PDF, Word, etc.)
- **Video Frame Capture**: Pause videos and capture specific frames for OCR
- **OCR Technology**: Extract text from any uploaded media
- **Translation**: Click on any word to get its meaning/translation
- **Multi-language Support**: Urdu, English, Arabic, Persian, and more
- **Scalable Architecture**: Easy to add support for additional languages
- **Responsive Design**: Works on all devices

## Tech Stack

- **Framework**: Next.js 14
- **OCR**: Tesseract.js
- **Translation**: Google Translate API
- **Styling**: Tailwind CSS
- **File Upload**: React Dropzone
- **Video Processing**: React Player
